음향 확인 · 향우회기, 감사패·표창장, 꽃다발이 무대 옆에 있는지 확인 · 내빈 착석 확인

【1부】 기념식

인사 및 개회 안내

존경하는 재안산 홍성향우회 향우님 여러분, 그리고 바쁘신 가운데 귀한 걸음 해 주신 내빈 여러분, 반갑습니다. / 오늘 사회를 맡은 사무국장 이민자입니다.

고향 홍성의 정을 품고 안산에서 함께 살아가는 우리 향우들이 이렇게 한자리에 모였습니다. / 지금부터 재안산 홍성향우회 제10·11대 회장 이·취임식 1부 기념식을 시작하겠습니다.

1. 향우회기 입장

먼저 향우회기 입장이 있겠습니다. / 김영창 조직국장님께서 향우회기를 들고 입장하시겠습니다. / 모두 큰 박수로 맞이해 주시기 바랍니다.

입장 음악 · 향우회기 단상 옆 거치 후 박수 마무리

2. 개회 선언

다음은 개회 선언이 있겠습니다. / 윤승노 수석부회장님께서 개회를 선언해 주시겠습니다.

윤승노 수석부회장 단상으로 → 개회 선언 → 자리로

감사합니다.

3. 국민의례

다음은 국민의례가 있겠습니다. / 모두 자리에서 일어나 단상의 국기를 향해 서 주시기 바랍니다.

국기에 대하여 경례.

경례 음악 또는 맹세문이 끝나면

바로.

다음은 애국가 제창이 있겠습니다. / 애국가는 1절만 부르겠습니다.

애국가 반주 (1절)

다음은 순국선열과 호국영령, 그리고 먼저 우리 곁을 떠나신 향우님들의 명복을 빌며 묵념을 올리겠습니다. / 일동 묵념.

약 10~15초

바로. / 모두 자리에 앉아 주시기 바랍니다.

4. 참석 내·외빈 소개

다음은 오늘 이 자리를 빛내 주신 내·외빈 소개가 있겠습니다. / 방현용 회장님께서 소개해 주시겠습니다. / 소개받으신 분께서는 자리에서 잠시 일어나 인사해 주시고, 향우님들께서는 큰 박수로 환영해 주시기 바랍니다.

방현용 회장 소개 → 내빈 명단은 회장님께 미리 전달 (홍성군수, 이민근 안산시장, 유운중 충청향우회장, 이상부 초대회장, 보령·청양·세종 향우회 등)

감사합니다.

5. 감사패 및 표창장 수여

다음은 감사패 및 표창장 수여가 있겠습니다. / 수상자께서는 호명하면 단상 앞으로 나와 주시기 바랍니다.

먼저 홍성군수 표창입니다. / ○○○ 님. / 시상은 홍성군수님께서 해 주시겠습니다.

다음은 안산시장 표창입니다. / ○○○ 님. / 시상은 이민근 안산시장님께서 해 주시겠습니다.

다음은 향우회 감사패입니다. / 이민자 사무국장, 손기숙 감사님. / 시상은 방현용 회장님께서 해 주시겠습니다.

한 사람씩 수여 → 사진 촬영 → 박수. 본인 수상 순서에서는 대신 진행할 사람(○○○)이 호명

수상하신 모든 분께 다시 한번 큰 축하의 박수를 부탁드립니다.

6. 회장 인사

8. 임원 인준

다음은 임원 인준이 있겠습니다. / 방현용 회장님께서 진행해 주시겠습니다.

방현용 회장 진행 (참고 문안)

우리 회칙 제3장 제8조 1항에 따라, 상임이사회에서 추대한 윤승노 수석부회장을 제11대 회장으로 인준하고자 합니다. / 찬성하시는 향우님께서는 박수로 동의해 주시기 바랍니다.

박수 → "출석 과반수 찬성으로 인준되었음을 선포합니다." (의사봉 3타)

다음은 회칙 제8조 2항에 따른 감사 인준입니다. / 손기숙 님을 감사로 인준하고자 합니다. / 박수로 동의해 주시기 바랍니다.

박수 → "인준되었음을 선포합니다." (의사봉 3타)

이상으로 1부 기념식을 모두 마치겠습니다. / 잠시 무대를 정리한 뒤 2부 회장 이·취임식을 이어가겠습니다.

약 3~5분 정리 · 2부용 향우회기, 감사패, 꽃다발 준비

【2부】 회장 이·취임식

시작 안내

향우님 여러분, 자리에 앉아 주시기 바랍니다. / 지금부터 재안산 홍성향우회 제10·11대 회장 이·취임식을 시작하겠습니다.

1. 향우회기 인계

먼저 향우회기 인계가 있겠습니다. / 제10대 방현용 회장님께서 제11대 윤승노 회장님께 향우회기를 넘겨 드리겠습니다. / 두 분 회장님은 단상 앞으로 나와 주시기 바랍니다.

방현용 회장 → 윤승노 회장 향우회기 전달 → 함께 사진 촬영

새로운 출발을 함께 축하하는 큰 박수 부탁드립니다.

2. 감사패 전달 및 꽃다발 증정

다음은 이임하시는 방현용 회장님께 감사패와 꽃다발을 드리는 순서입니다. / 윤승노 회장님께서 전달해 주시겠습니다.

감사패 문안을 읽어 드리겠습니다.

감사패 문안 낭독 (문구 확정 후 여기에 붙여넣기)

( 감사패 문안 )

전달 → 꽃다발 → 사진 촬영

그동안 향우회를 위해 애써 주신 방현용 회장님께 다시 한번 감사의 박수를 보내 주시기 바랍니다.

3. 이임사

다음은 방현용 회장님의 이임사가 있겠습니다. / 큰 박수로 모시겠습니다.

이임사 후

감사합니다. / 그동안 정말 수고 많으셨습니다.

4. 취임사

다음은 오늘의 주인공이십니다. / 제11대 윤승노 회장님의 취임사가 있겠습니다. / 뜨거운 박수로 맞이해 주시기 바랍니다.

취임사 후

감사합니다. / 새 회장님과 함께 더 힘차게 나아갈 우리 향우회에 큰 박수 부탁드립니다.

5. 축사

다음은 축사가 있겠습니다. / 먼저 홍성군수님을 모시겠습니다.

축사 후 "감사합니다."

다음은 이민근 안산시장님의 축사가 있겠습니다. / 큰 박수로 모시겠습니다.

축사 후 "감사합니다." · 불참 시 축전 대독: "○○님께서 일정상 함께하지 못하시고 축전을 보내 주셨습니다. 대신 읽어 드리겠습니다."

6. 임원진 소개

다음은 제11대 임원진 소개가 있겠습니다. / 윤승노 회장님께서 소개해 주시겠습니다. / 호명받으신 임원께서는 단상 앞으로 나와 주시기 바랍니다.

임원 명단은 회장님께 미리 전달 (임원 명단 확정 후) · 전원 단상 앞 정렬 → 단체 인사 → 사진 촬영

앞으로 향우회를 위해 애써 주실 임원진께 격려의 박수를 부탁드립니다.

7. 축하 케이크 커팅 및 건배 제의

다음은 축하 케이크 커팅과 건배 제의가 있겠습니다. / 이상부 초대회장님과 두 분 회장님, 그리고 내빈 여러분께서는 케이크 앞으로 나와 주시기 바랍니다.

케이크 앞 정렬 · 커팅 칼 준비

하나, 둘, 셋 하면 함께 커팅해 주시기 바랍니다. / 하나, 둘, 셋!

박수 · 사진 촬영 · 건배 잔 채우기 안내

향우님 여러분, 앞에 놓인 잔을 채워 주시기 바랍니다. / 이상부 초대회장님께서 건배를 제의해 주시겠습니다.

건배 제의 · 건배사 예시: "홍성!" → "하나로!"

8. 폐회

이것으로 재안산 홍성향우회 제10·11대 회장 이·취임식을 모두 마치겠습니다. / 끝까지 함께해 주신 향우님들과 내빈 여러분께 진심으로 감사드립니다.
