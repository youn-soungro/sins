# 주회/모임 공지문 템플릿

아래는 상황별 뼈대다. 실제 발송 시 날짜·장소·순서는 사용자가 준 정보로 채우고,
비어 있으면 [ ]로 표시해 무엇을 확인해야 하는지 드러낸다.

---

## 1) 기본형 (정기 주회 공지)

```
안산광덕 로타리클럽 회원 여러분께

[존경하는 회원 여러분, 안녕하십니까.] 짧은 인사·계절 인사 한 줄.

다음과 같이 [제○차 정기주회 / ○월 정기모임]을 안내드립니다.
회원 여러분의 많은 참석 부탁드립니다.

■ 일시: [2026년 ○월 ○일(요일) 오후 ○시]
■ 장소: [상호 / 주소]
■ 회비: [금액 / 없음]
■ 준비물: [없음 / 내용]

【주요 순서】
1. 개회 및 국민의례
2. 회장 인사
3. [식사 / 안건 / 특별순서]
4. 공지사항
5. 폐회

문의: [총무 대호 하관철 / 연락처]

회원 여러분의 건승을 기원합니다.
감사합니다.

안산광덕 로타리클럽 [회장 ○○ ○○○ / 총무 대호 하관철] 드림
```

---

## 2) 이사회 공지

```
안산광덕 로타리클럽 이사 여러분께

아래와 같이 [제○차 이사회]를 개최하오니
이사님들께서는 부득이한 사정이 없는 한 참석하여 주시기 바랍니다.

■ 일시: [ ]
■ 장소: [ ]

【부의 안건】
1. [ ]
2. [ ]
3. 기타 토의사항

문의: 총무 대호 하관철 [연락처]

안산광덕 로타리클럽 회장 [ ] 드림
```

## 3) 단체톡(카톡) 간단 공지 — 좀 더 부드럽게

```
[회원 여러분 안녕하세요! 😊 — 이모지는 상황에 맞게]
이번 주 정기주회 안내드립니다.

📅 [○월 ○일(요일) 오후 ○시]
📍 [장소]

식사 준비 관계로 참석 여부 회신 부탁드립니다.
많이 나와 주세요! 감사합니다.

총무 대호 하관철 드림
```

---

## 작성 규칙

- 직책·이름은 "직책 + 호 성명" (예: "총무 대호 하관철"). 호+이름 표기가 로타리 관례.
- 정중한 격식체가 기본. 카톡 간단 공지만 부드럽게.
- 날짜는 요일까지, 시간은 오전/오후로 명확히.
- 확정 안 된 정보는 지어내지 말고 [ ]로 남긴다.
- 마지막 서명은 회장 또는 총무 명의. 누구 명의인지 모르면 사용자에게 확인.
