# 실행 방법

디자인재성 직원 일당·출퇴근 관리 시스템을 실제로 띄우는 방법입니다.

상황에 따라 **셋 중 하나**를 고르시면 됩니다.

| 방법 | 이럴 때 | 난이도 | 비용 |
|---|---|---|---|
| **① 인터넷 배포 (권장)** | 직원들이 밖에서 휴대폰으로 출퇴근 찍어야 할 때 | 보통 | 무료로 시작 가능 |
| **② 내 PC에서 테스트** | 먼저 써보고 결정하고 싶을 때 | 쉬움 | 무료 |
| **③ 회사 서버 / NAS** | 데이터를 회사 안에만 두고 싶을 때 | 어려움 | 서버 비용 |

> **중요**
> 직원이 현장·외부에서 휴대폰으로 출퇴근을 찍으려면 **①번(인터넷 배포)** 이어야 합니다.
> ②번은 같은 사무실 와이파이 안에서만 접속됩니다.
>
> 이미 **카페24·가비아 같은 웹호스팅**으로 홈페이지를 운영 중이시라면
> → [웹호스팅을 쓰고 계신 경우](#웹호스팅카페24가비아-등을-쓰고-계신-경우) 를 보세요.
> 그 서버에는 설치할 수 없지만, **회사 도메인은 그대로 쓰실 수 있습니다.**

## ① 인터넷 배포 — 실제 운영용 (권장)

무료로 시작할 수 있고, 직원들은 카톡으로 링크만 받으면 바로 씁니다.

### 1단계 · 데이터베이스 만들기 (5분)

1. <https://neon.tech> 접속 → GitHub 계정으로 가입 (무료)
2. `Create project` 클릭
   - Project name: `sins-attendance`
   - Region: **Asia Pacific (Singapore)** 선택 (한국에서 가장 빠릅니다)
3. 만들어지면 화면에 나오는 **Connection string** 을 복사해 둡니다.
   `postgresql://...` 로 시작하는 긴 주소입니다.

> Neon 대신 Supabase(<https://supabase.com>)를 쓰셔도 됩니다. 똑같이 접속주소만 복사하면 됩니다.

### 2단계 · 배포하기 (5분)

1. <https://vercel.com> 접속 → GitHub 계정으로 가입 (무료)
2. `Add New...` → `Project` → 이 저장소(`sins`) 선택 → `Import`
3. **아래 3가지를 반드시 바꿔주세요.**

   **① Root Directory**
   `Edit` 를 눌러 **`attendance`** 로 지정합니다. (이걸 안 하면 배포가 실패합니다)

   **② Build Command**
   `Override` 를 켜고 아래를 입력합니다.
   ```
   npm run deploy:build
   ```

   **③ Environment Variables** — 아래 4개를 입력합니다.

   | Name | Value |
   |---|---|
   | `DATABASE_URL` | 1단계에서 복사한 Neon 접속주소 |
   | `JWT_SECRET` | 아무 영문·숫자 32자 이상 (아래 참고) |
   | `ADMIN_LOGIN_ID` | 원하는 관리자 아이디 (예: `admin`) |
   | `ADMIN_PASSWORD` | 원하는 관리자 비밀번호 |

   `JWT_SECRET` 은 아무렇게나 길게 치시면 됩니다. 예:
   ```
   designjaeseong-2026-geuntae-secret-key-9f3a7c2e5b1d
   ```
   > 이 값은 로그인 보안에 쓰이므로 **남에게 알려주지 마세요.**
   > 나중에 바꾸면 모든 사람이 다시 로그인해야 합니다.

4. `Deploy` 클릭 → 2~3분 기다립니다.

### 3단계 · 접속

배포가 끝나면 `https://오오오.vercel.app` 같은 주소가 나옵니다.

| 대상 | 주소 |
|---|---|
| 관리자 (사장님) | `https://주소.vercel.app/login` |
| 직원 | `https://주소.vercel.app/employee/login` |

**직원에게는 `/employee/login` 주소만 카톡으로 보내주시면 됩니다.**

직원 휴대폰에서 그 링크를 열고 →
- 아이폰: 하단 공유 버튼 → `홈 화면에 추가`
- 안드로이드: 우측 상단 점 3개 → `홈 화면에 추가`

하면 앱처럼 아이콘이 생겨서 매일 편하게 쓸 수 있습니다.

## ② 내 PC에서 테스트

먼저 써보고 싶으실 때 쓰는 방법입니다. **같은 와이파이 안에서만** 접속됩니다.

### 준비물 설치 (처음 한 번만)

1. **Node.js** — <https://nodejs.org> 에서 `LTS` 버전 다운로드 후 설치 (계속 `다음` 눌러도 됩니다)
2. **PostgreSQL** — <https://www.postgresql.org/download/windows/> 에서 설치
   - 설치 중 **비밀번호를 입력하라고 나오면 꼭 적어두세요.** 나중에 필요합니다.
   - 나머지는 기본값 그대로 두시면 됩니다.

### 실행

`시작` → `cmd` 검색 → 명령 프롬프트를 열고 아래를 순서대로 입력합니다.

```bash
git clone https://github.com/youn-soungro/sins.git
cd sins\attendance
npm install
```

`.env` 파일 만들기 — 메모장으로 `attendance` 폴더 안에 `.env` 라는 이름의 파일을 만들고 아래 내용을 넣습니다.

```
DATABASE_URL="postgresql://postgres:설치할때정한비밀번호@localhost:5432/sins_attendance?schema=public"
JWT_SECRET="designjaeseong-2026-geuntae-secret-key-9f3a7c2e5b1d"
ADMIN_LOGIN_ID="admin"
ADMIN_PASSWORD="admin1234"
```

데이터베이스를 만들고 실행합니다.

```bash
createdb -U postgres sins_attendance
npm run setup
npm run build
npm start
```

브라우저에서 <http://localhost:3100> 을 열면 됩니다.

> 다음부터는 `npm start` 만 입력하면 됩니다.
> 창을 닫으면 꺼지므로, 쓰는 동안은 창을 열어두셔야 합니다.

### 같은 사무실 직원 휴대폰으로 접속하기

명령 프롬프트에 `ipconfig` 를 치면 `IPv4 주소`가 나옵니다 (예: `192.168.0.15`).
직원 휴대폰에서 같은 와이파이에 연결한 뒤 `http://192.168.0.15:3100/employee/login` 로 접속하면 됩니다.

## ③ 회사 서버 / NAS

데이터를 회사 밖으로 내보내지 않으려는 경우입니다.

```bash
cd attendance
npm install
# .env 에 회사 PostgreSQL 주소 입력
BUILD_STANDALONE=1 npm run build
node .next/standalone/server.js
```

외부(현장)에서도 접속하려면 공유기에서 **포트포워딩**과 **고정 IP 또는 DDNS** 설정이 필요합니다.
이 부분은 인터넷 회선 업체나 NAS 설치 업체에 문의하시는 것이 빠릅니다.

## 웹호스팅(카페24·가비아 등)을 쓰고 계신 경우

**결론부터 말씀드리면, 지금 쓰시는 웹호스팅에는 이 프로그램을 설치할 수 없습니다.**

웹호스팅은 PHP 전용 상품이라 이 프로그램이 필요로 하는 Node.js 가 실행되지 않습니다.
호스팅 업체에 문의하셔도 같은 답을 받으실 겁니다.

하지만 **홈페이지를 바꾸거나 옮기실 필요는 전혀 없습니다.** 아래처럼 하시면 됩니다.

### 이렇게 하시면 됩니다

```
기존 홈페이지 (웹호스팅)          근태 프로그램 (Vercel · 무료)
designjaeseong.co.kr      →      work.designjaeseong.co.kr
   그대로 유지                        새로 배포
```

홈페이지는 지금 그대로 두고, 근태 프로그램만 따로 배포한 뒤
**회사 도메인의 주소 하나를 연결**하는 방식입니다.
직원들은 회사 도메인으로 접속하니 남의 서비스를 쓰는 느낌이 없습니다.

### 1단계 · 배포하기

위의 **`① 인터넷 배포`** 를 그대로 따라 하시면 됩니다. (약 10분, 무료)
끝나면 `https://OOOO.vercel.app` 주소가 나옵니다.

여기까지만 해도 바로 쓸 수 있습니다. 회사 도메인을 붙이고 싶으시면 2단계로 갑니다.

### 2단계 · 회사 도메인 연결하기 (선택)

**Vercel 쪽 설정**

1. Vercel 프로젝트 → `Settings` → `Domains`
2. `Add` 를 누르고 원하는 주소를 입력합니다.
   예: `work.designjaeseong.co.kr` 또는 `근태.designjaeseong.co.kr`
   > 홈페이지 주소 앞에 단어만 붙이는 형태(서브도메인)여야 합니다.
   > 홈페이지 주소 자체(`designjaeseong.co.kr`)를 넣으면 기존 홈페이지가 안 열리게 되니 **절대 넣지 마세요.**
3. Vercel 이 `CNAME` 값을 하나 보여줍니다. (`cname.vercel-dns.com` 같은 형태)
   **화면에 표시된 값을 그대로 복사**해 둡니다.

**호스팅 업체 쪽 설정**

도메인을 산 곳(카페24·가비아 등)에 로그인해서 `DNS 관리` 로 들어갑니다.

| 항목 | 입력값 |
|---|---|
| 타입 | `CNAME` |
| 호스트 / 이름 | `work` (앞에 붙일 단어만) |
| 값 / 레코드 | Vercel 이 보여준 주소 |

- **카페24**: `나의서비스관리` → `도메인` → `DNS 관리` → `CNAME 등록`
- **가비아**: `My가비아` → `DNS 관리툴` → `도메인 선택` → `DNS 설정` → `레코드 추가`

저장 후 10분~1시간 정도 기다리면 연결됩니다. 보안접속(https)은 Vercel 이 알아서 붙여줍니다.

> **기존 홈페이지는 영향받지 않습니다.**
> `work` 라는 새 주소를 추가하는 것뿐이라, `designjaeseong.co.kr` 은 그대로 열립니다.

### 3단계 · 홈페이지에 출퇴근 버튼 달기 (선택)

`웹호스팅-업로드용` 폴더에 있는 **`attendance.html`** 파일 하나만 기존 홈페이지에 올리면,
직원들이 회사 홈페이지 주소로 들어와서 출퇴근을 찍을 수 있습니다.

1. `attendance.html` 을 메모장으로 엽니다
2. 파일 안의 `주소를-여기에-입력.vercel.app` 두 군데를 실제 주소로 바꿉니다
3. FTP 로 접속해 기존 `index.html` 이 있는 폴더(보통 `/www` 또는 `/public_html`)에 올립니다
4. 직원에게 `회사홈페이지주소/attendance.html` 을 알려줍니다

> 기존 홈페이지 파일은 **건드리지 마세요.** 새 파일 하나만 추가하는 것이라 안전합니다.

자세한 내용은 `웹호스팅-업로드용/읽어보세요.txt` 에 적어두었습니다.

### 굳이 회사 서버에 직접 두고 싶으시다면

데이터를 반드시 회사 서버 안에 두어야 한다면 **서버호스팅(VPS)** 으로 바꾸셔야 합니다.
월 2~3만원대이며, 리눅스 서버 관리 지식이 필요합니다.
그런 경우 위의 `③ 회사 서버 / NAS` 방식으로 설치하시면 됩니다.

솔직히 말씀드리면, 직원 5~15명 규모라면 **① 방식(Vercel + 회사 도메인 연결)이 비용·안정성·관리 부담 모든 면에서 낫습니다.**
서버가 멈추거나 백업을 신경 쓰실 일이 없습니다.

```bash

```


<http://localhost:3100> 으로 접속됩니다.

> **주의**: `node_modules` 폴더는 GitHub 에 올라가 있지 않습니다.

## 기존 홈페이지와 같은 PC에서 함께 돌리기

디자인재성 홈페이지(`server.js`)와 이 근태 프로그램은 **서로 완전히 별개**라
한 PC에서 같이 켜두어도 됩니다. 단, 아래 두 가지만 확인하세요.

### 1. 포트가 겹치지 않는지

| 프로그램 | 포트 | 주소 |
|---|---|---|
| 기존 홈페이지 (`server.js`) | **3000** | http://localhost:3000 |
| 근태 프로그램 | **3100** | http://localhost:3100 |

이미 겹치지 않게 맞춰 두었으므로 그대로 쓰시면 됩니다.
혹시 바꾸고 싶으시면 `attendance/package.json` 의 `start` 항목에서 `-p 3100` 숫자만 고치면 됩니다.

> 홈페이지 포트를 바꾸고 싶으시면 `server.js` 를 고치지 마시고,
> 실행할 때 `set PORT=3200 && node server.js` 처럼 지정하시면 됩니다.
> (`server.js` 가 `process.env.PORT` 를 먼저 보도록 이미 되어 있습니다)

### 2. 폴더가 서로 섞이지 않는지

```
H:\홈페이지 6 0729\      ← 기존 홈페이지 (그대로 두세요)
H:\근태관리ttendance\   ← 근태 프로그램 (완전히 다른 폴더)
```

**두 폴더를 절대 합치지 마세요.** 각각 따로 두면 서로 영향이 없습니다.

### 데이터가 섞일 걱정은 없습니다

| | 기존 홈페이지 | 근태 프로그램 |
|---|---|---|
| 데이터 저장 | `data` 폴더의 JSON 파일 | PostgreSQL 데이터베이스 |
| 업로드 사진 | `uploads` 폴더 | 사용 안 함 |

저장 방식 자체가 달라서 서로의 데이터를 건드릴 수 없습니다.

`디자인재성 공장`은 이미 만들어져 있습니다. **`수정`을 눌러 GPS 좌표를 넣어주세요.**

> 💡 **가장 쉬운 방법**: 공장에 계실 때 휴대폰으로 관리자 화면에 접속해서
> `근무지관리 → 수정 → 📍 현재 위치 좌표 가져오기` 를 누르면 좌표가 자동으로 들어갑니다.

허용반경은 공장 200m, 현장 300m 정도가 무난합니다.

### 3. 현장관리
진행 중인 외부 현장을 등록합니다. 직원이 출근할 때 여기서 고르게 됩니다.

### 4. 직원관리
`+ 직원 등록` 으로 직원을 넣습니다. 이름과 휴대폰번호만 있어도 등록됩니다.

- **직원번호**는 비워두면 자동으로 붙습니다
- **PIN**은 비워두면 **휴대폰번호 뒤 4자리**가 됩니다
- 등록하면 화면에 초기 PIN 이 뜨니 **직원에게 알려주세요**
- 일당은 `공장 일당`, `현장 일당`을 각각 넣으면 근무지에 따라 자동 적용됩니다
- 계산방식은 보통 **`방식 C · 일당 + 연장수당`** 을 씁니다
- 연장 시간당 단가를 `0` 으로 두면 **일당 ÷ 8시간**으로 알아서 계산합니다 (250,000원이면 31,250원)

`월별정산` → 월 선택 → **`전체 정산 실행`** 버튼 한 번.

지급은 `지급관리`에서 처리하고, 필요하면 `엑셀 다운로드`에서 내려받으시면 됩니다.

## 자주 겪는 문제

**직원이 "출근 버튼을 못 눌렀다"고 할 때**
직원이 `수정요청`으로 시간을 요청 → 관리자가 `수정요청` 메뉴에서 승인하면 반영됩니다.
관리자가 `출퇴근 관리`에서 직접 고칠 수도 있습니다. (수정사유 입력 필수, 이력이 남습니다)

**"지정된 근무지에서 멀리 떨어져 있습니다"가 뜰 때**
근무지 GPS 좌표가 안 들어갔거나 허용반경이 좁은 경우입니다.
`근무지관리`에서 좌표와 반경을 확인해 주세요.
직원이 `확인`을 누르면 출근은 되고, 관리자 확인 대상으로 표시됩니다.

**퇴근을 안 찍고 퇴근한 직원이 있을 때**
16시간이 지나면 자동으로 마감되고 노란색으로 표시됩니다.
`출퇴근 관리`에서 실제 퇴근시간으로 고쳐주시면 됩니다.

**직원이 PIN을 잊었을 때**
`직원관리 → 직원 상세 → 직원정보 수정 → PIN 재설정` 에서 새로 정해주시면 됩니다.
