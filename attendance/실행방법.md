# 실행 방법

디자인재성 직원 일당·출퇴근 관리 시스템을 실제로 띄우는 방법입니다.

상황에 따라 **셋 중 하나**를 고르시면 됩니다.

| 방법 | 이럴 때 | 난이도 | 비용 |
|---|---|---|---|
| **① 인터넷 배포 (권장)** | 직원들이 밖에서 휴대폰으로 출퇴근 찍어야 할 때 | 보통 | 무료로 시작 가능 |
| **② 내 PC에서 테스트** | 먼저 써보고 결정하고 싶을 때 | 쉬움 | 무료 |
| **③ 회사 서버 / NAS** | 데이터를 회사 안에만 두고 싶을 때 | 어려움 | 서버 비용 |

> **중요**
> 직원이 현장·외부에서 휴대폰으로 출퇴근을 찍으려면 **①번(인터넷 배포)** 이어야 합니다.
> ②번은 같은 사무실 와이파이 안에서만 접속됩니다.

---

## ① 인터넷 배포 — 실제 운영용 (권장)

무료로 시작할 수 있고, 직원들은 카톡으로 링크만 받으면 바로 씁니다.

### 1단계 · 데이터베이스 만들기 (5분)

1. <https://neon.tech> 접속 → GitHub 계정으로 가입 (무료)
2. `Create project` 클릭
   - Project name: `sins-attendance`
   - Region: **Asia Pacific (Singapore)** 선택 (한국에서 가장 빠릅니다)
3. 만들어지면 화면에 나오는 **Connection string** 을 복사해 둡니다.
   `postgresql://...` 로 시작하는 긴 주소입니다.

> Neon 대신 Supabase(<https://supabase.com>)를 쓰셔도 됩니다. 똑같이 접속주소만 복사하면 됩니다.

### 2단계 · 배포하기 (5분)

1. <https://vercel.com> 접속 → GitHub 계정으로 가입 (무료)
2. `Add New...` → `Project` → 이 저장소(`sins`) 선택 → `Import`
3. **아래 3가지를 반드시 바꿔주세요.**

   **① Root Directory**
   `Edit` 를 눌러 **`attendance`** 로 지정합니다. (이걸 안 하면 배포가 실패합니다)

   **② Build Command**
   `Override` 를 켜고 아래를 입력합니다.
   ```
   npm run deploy:build
   ```

   **③ Environment Variables** — 아래 4개를 입력합니다.

   | Name | Value |
   |---|---|
   | `DATABASE_URL` | 1단계에서 복사한 Neon 접속주소 |
   | `JWT_SECRET` | 아무 영문·숫자 32자 이상 (아래 참고) |
   | `ADMIN_LOGIN_ID` | 원하는 관리자 아이디 (예: `admin`) |
   | `ADMIN_PASSWORD` | 원하는 관리자 비밀번호 |

   `JWT_SECRET` 은 아무렇게나 길게 치시면 됩니다. 예:
   ```
   designjaeseong-2026-geuntae-secret-key-9f3a7c2e5b1d
   ```
   > 이 값은 로그인 보안에 쓰이므로 **남에게 알려주지 마세요.**
   > 나중에 바꾸면 모든 사람이 다시 로그인해야 합니다.

4. `Deploy` 클릭 → 2~3분 기다립니다.

### 3단계 · 접속

배포가 끝나면 `https://오오오.vercel.app` 같은 주소가 나옵니다.

| 대상 | 주소 |
|---|---|
| 관리자 (사장님) | `https://주소.vercel.app/login` |
| 직원 | `https://주소.vercel.app/employee/login` |

**직원에게는 `/employee/login` 주소만 카톡으로 보내주시면 됩니다.**

직원 휴대폰에서 그 링크를 열고 →
- 아이폰: 하단 공유 버튼 → `홈 화면에 추가`
- 안드로이드: 우측 상단 점 3개 → `홈 화면에 추가`

하면 앱처럼 아이콘이 생겨서 매일 편하게 쓸 수 있습니다.

## ② 내 PC에서 테스트

먼저 써보고 싶으실 때 쓰는 방법입니다. **같은 와이파이 안에서만** 접속됩니다.

### 준비물 설치 (처음 한 번만)

1. **Node.js** — <https://nodejs.org> 에서 `LTS` 버전 다운로드 후 설치 (계속 `다음` 눌러도 됩니다)
2. **PostgreSQL** — <https://www.postgresql.org/download/windows/> 에서 설치
   - 설치 중 **비밀번호를 입력하라고 나오면 꼭 적어두세요.** 나중에 필요합니다.
   - 나머지는 기본값 그대로 두시면 됩니다.

### 실행

`시작` → `cmd` 검색 → 명령 프롬프트를 열고 아래를 순서대로 입력합니다.

```bash
git clone https://github.com/youn-soungro/sins.git
cd sins\attendance
npm install
```

`.env` 파일 만들기 — 메모장으로 `attendance` 폴더 안에 `.env` 라는 이름의 파일을 만들고 아래 내용을 넣습니다.

```
DATABASE_URL="postgresql://postgres:설치할때정한비밀번호@localhost:5432/sins_attendance?schema=public"
JWT_SECRET="designjaeseong-2026-geuntae-secret-key-9f3a7c2e5b1d"
ADMIN_LOGIN_ID="admin"
ADMIN_PASSWORD="admin1234"
```

데이터베이스를 만들고 실행합니다.

```bash
createdb -U postgres sins_attendance
npm run setup
npm run build
npm start
```

브라우저에서 <http://localhost:3000> 을 열면 됩니다.

> 다음부터는 `npm start` 만 입력하면 됩니다.
> 창을 닫으면 꺼지므로, 쓰는 동안은 창을 열어두셔야 합니다.

### 같은 사무실 직원 휴대폰으로 접속하기

명령 프롬프트에 `ipconfig` 를 치면 `IPv4 주소`가 나옵니다 (예: `192.168.0.15`).
직원 휴대폰에서 같은 와이파이에 연결한 뒤 `http://192.168.0.15:3000/employee/login` 로 접속하면 됩니다.

## ③ 회사 서버 / NAS

데이터를 회사 밖으로 내보내지 않으려는 경우입니다.

```bash
cd attendance
npm install
# .env 에 회사 PostgreSQL 주소 입력
BUILD_STANDALONE=1 npm run build
node .next/standalone/server.js
```

외부(현장)에서도 접속하려면 공유기에서 **포트포워딩**과 **고정 IP 또는 DDNS** 설정이 필요합니다.
이 부분은 인터넷 회선 업체나 NAS 설치 업체에 문의하시는 것이 빠릅니다.

## 처음 접속한 뒤 할 일

관리자로 로그인한 다음, 아래 순서대로 설정하시면 바로 쓸 수 있습니다.

### 1. 설정
회사 기본 근무시간을 맞춥니다. (기본값 08:00~17:00, 휴게 12:00~13:00, 기본근무 8시간)

### 2. 근무지관리
`디자인재성 공장`은 이미 만들어져 있습니다. **`수정`을 눌러 GPS 좌표를 넣어주세요.**

> 💡 **가장 쉬운 방법**: 공장에 계실 때 휴대폰으로 관리자 화면에 접속해서
> `근무지관리 → 수정 → 📍 현재 위치 좌표 가져오기` 를 누르면 좌표가 자동으로 들어갑니다.

허용반경은 공장 200m, 현장 300m 정도가 무난합니다.

### 3. 현장관리
진행 중인 외부 현장을 등록합니다. 직원이 출근할 때 여기서 고르게 됩니다.

### 4. 직원관리
`+ 직원 등록` 으로 직원을 넣습니다. 이름과 휴대폰번호만 있어도 등록됩니다.

- **직원번호**는 비워두면 자동으로 붙습니다
- **PIN**은 비워두면 **휴대폰번호 뒤 4자리**가 됩니다
- 등록하면 화면에 초기 PIN 이 뜨니 **직원에게 알려주세요**
- 일당은 `공장 일당`, `현장 일당`을 각각 넣으면 근무지에 따라 자동 적용됩니다
- 계산방식은 보통 **`방식 C · 일당 + 연장수당`** 을 씁니다
- 연장 시간당 단가를 `0` 으로 두면 **일당 ÷ 8시간**으로 알아서 계산합니다 (250,000원이면 31,250원)

## 매달 하실 일

`월별정산` → 월 선택 → **`전체 정산 실행`** 버튼 한 번.

근무일수, 연장시간, 일당, 추가수당, 공제, 최종 지급액까지 전부 자동으로 나옵니다.
정산을 확정하면 직원이 자기 휴대폰 `내 정산내역`에서 확인할 수 있습니다.

지급은 `지급관리`에서 처리하고, 필요하면 `엑셀 다운로드`에서 내려받으시면 됩니다.

## 자주 겪는 문제

**직원이 "출근 버튼을 못 눌렀다"고 할 때**
직원이 `수정요청`으로 시간을 요청 → 관리자가 `수정요청` 메뉴에서 승인하면 반영됩니다.
관리자가 `출퇴근 관리`에서 직접 고칠 수도 있습니다. (수정사유 입력 필수, 이력이 남습니다)

**"지정된 근무지에서 멀리 떨어져 있습니다"가 뜰 때**
근무지 GPS 좌표가 안 들어갔거나 허용반경이 좁은 경우입니다.
`근무지관리`에서 좌표와 반경을 확인해 주세요.
직원이 `확인`을 누르면 출근은 되고, 관리자 확인 대상으로 표시됩니다.

**퇴근을 안 찍고 퇴근한 직원이 있을 때**
16시간이 지나면 자동으로 마감되고 노란색으로 표시됩니다.
`출퇴근 관리`에서 실제 퇴근시간으로 고쳐주시면 됩니다.

**직원이 PIN을 잊었을 때**
`직원관리 → 직원 상세 → 직원정보 수정 → PIN 재설정` 에서 새로 정해주시면 됩니다.

## 데이터 백업

```bash
cd attendance
npm run backup
```

`attendance/backups` 폴더에 저장됩니다.

①번(Vercel + Neon)으로 쓰시면 Neon 이 자동으로 백업하므로 따로 안 하셔도 됩니다.
②·③번으로 쓰신다면 **한 달에 한 번은 꼭 실행**하시고, 나온 파일을 다른 곳(USB, 구글드라이브 등)에 복사해 두세요.
