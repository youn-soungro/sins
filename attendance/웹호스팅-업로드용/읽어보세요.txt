[ 이 폴더는 무엇인가요? ]

지금 쓰고 계신 웹호스팅(카페24·가비아 등)에는 이 근태관리 프로그램을
직접 설치할 수 없습니다. 웹호스팅은 PHP 전용이라 Node.js가 실행되지 않기 때문입니다.

대신 이 폴더의 attendance.html 파일 하나만 기존 홈페이지에 올려두면,
직원들이 회사 홈페이지 주소로 들어와서 출퇴근을 찍을 수 있습니다.


===========================================================
[ 가장 중요 ] 기존 홈페이지를 손상시키지 않는 3가지 원칙
===========================================================

원칙 1. 올리기 전에 먼저 백업한다
   FTP 프로그램으로 서버의 모든 파일을 PC로 "내려받기" 해서
   날짜별 폴더에 보관해 두세요. (예: H:\홈페이지_백업_20260819)
   이것만 해두면 무슨 일이 생겨도 되돌릴 수 있습니다.

원칙 2. 같은 이름의 파일이 이미 있는지 반드시 확인한다
   FTP로 접속해서 attendance.html 이라는 파일이 이미 있는지 봅니다.
   - 없다  -> 그대로 올리면 됩니다. 가장 안전합니다.
   - 있다  -> 절대 덮어쓰지 마세요. 파일 이름을 바꿔서 올리세요.
             (예: chulgeun.html, work.html 처럼 겹치지 않는 이름)

원칙 3. 기존 파일은 절대 지우거나 덮어쓰지 않는다
   특히 아래 파일들은 홈페이지의 첫 화면이라 건드리면 안 됩니다.
       index.html   index.htm   index.php   main.html   default.html
   우리가 하는 일은 "새 파일 1개 추가"일 뿐입니다.
   기존 파일은 하나도 바꾸지 않습니다.


===========================================================
[ 사용 방법 ]
===========================================================

1. 먼저 실행방법.md 의 "① 인터넷 배포" 를 따라 배포합니다.
   배포가 끝나면 https://OOOO.vercel.app 같은 주소가 나옵니다.

2. attendance.html 을 메모장으로 엽니다.

3. 아래 두 줄에서 "주소를-여기에-입력.vercel.app" 부분을
   2번에서 받은 실제 주소로 바꿉니다. (두 군데 모두)

   <a class="btn emp" href="https://주소를-여기에-입력.vercel.app/employee/login">
   <a class="btn adm" href="https://주소를-여기에-입력.vercel.app/login">

   예시)
   <a class="btn emp" href="https://sins-attendance.vercel.app/employee/login">
   <a class="btn adm" href="https://sins-attendance.vercel.app/login">

4. [백업] FTP로 접속해 서버 파일 전체를 PC로 내려받아 보관합니다. (원칙 1)

5. [확인] 같은 이름의 파일이 없는지 봅니다. (원칙 2)

6. attendance.html 을 기존 index.html 이 있는 폴더에 올립니다.
   보통 /www 또는 /public_html 폴더입니다.
   ※ 다른 파일은 선택하지 말고, 이 파일 하나만 올리세요.

7. 브라우저에서 아래 주소로 들어가 화면이 나오는지 확인합니다.

   http://회사홈페이지주소/attendance.html

8. 마지막으로 회사 홈페이지 첫 화면(http://회사홈페이지주소)도
   평소처럼 정상적으로 열리는지 꼭 확인하세요.

9. 이상이 없으면 직원들에게 7번 주소를 알려주면 됩니다.


===========================================================
[ 혹시 문제가 생겼다면 ]
===========================================================

- 홈페이지 첫 화면이 이상해졌다
  -> 4번에서 백업해 둔 파일을 FTP로 다시 올리면 원래대로 돌아옵니다.

- attendance.html 만 안 열린다
  -> 홈페이지에는 아무 문제가 없는 상태입니다.
     파일을 올린 폴더 위치가 맞는지만 확인하면 됩니다.

- 잘 모르겠다
  -> attendance.html 을 지우면 홈페이지는 원래 상태 그대로입니다.
     이 파일은 기존 홈페이지와 아무 연결이 없어서 지워도 영향이 없습니다.


===========================================================
[ 참고 ] 이 파일이 홈페이지를 망가뜨릴 수 없는 이유
===========================================================

attendance.html 은 다른 파일을 전혀 건드리지 않는 독립된 페이지입니다.
- 데이터베이스에 접속하지 않습니다
- 다른 파일을 불러오지 않습니다 (글꼴, 이미지, 스크립트 모두 없음)
- 파일 안에 링크 2개와 글자만 들어 있습니다

그래서 이 파일을 올리거나 지워도 기존 홈페이지는 아무 영향을 받지 않습니다.
단, 위의 "원칙 2"(같은 이름 파일 확인)만은 꼭 지켜주세요.
