# 디자인재성 직원 일당·출퇴근 통합 관리 시스템

직원은 휴대폰으로 출퇴근을 기록하고, 관리자는 PC·휴대폰에서 근무시간·일당·연장근무·
현장근무·지급금액까지 한 곳에서 관리하는 반응형 웹 시스템입니다.

---

## 1. 빠른 시작

### 준비물
- Node.js 20 이상
- PostgreSQL 14 이상

### 설치

```bash
cd attendance
npm install
cp .env.example .env      # 값을 실제 환경에 맞게 수정
```

`.env` 에서 반드시 바꿔야 하는 값:

| 항목 | 설명 |
|---|---|
| `DATABASE_URL` | PostgreSQL 접속 주소 |
| `JWT_SECRET` | 로그인 토큰 서명키. **32자 이상 임의 문자열로 반드시 변경** |
| `ADMIN_LOGIN_ID` / `ADMIN_PASSWORD` | 최초 관리자 계정 |

### 실행

```bash
npx prisma migrate deploy   # DB 테이블 생성
npm run seed                # 최초 관리자 계정 + 기본 설정 생성
npm run build
npm start                   # http://localhost:3000
```

개발 중에는 `npm run dev` 를 사용합니다.

### 접속 주소

| 대상 | 주소 |
|---|---|
| 관리자 | `/login` |
| 직원 | `/employee/login` |

직원은 앱 설치 없이 위 링크만 있으면 됩니다. 휴대폰 홈 화면에 추가해 두면 앱처럼 쓸 수 있습니다.

## 2. 계정

| 구분 | 로그인 방법 |
|---|---|
| 관리자 | 아이디 + 비밀번호 |
| 직원 | 휴대폰번호 + PIN |

직원 계정은 **직원 등록 시 자동으로 생성**됩니다.
PIN 을 따로 지정하지 않으면 **휴대폰번호 뒤 4자리**가 초기 PIN 이 됩니다.
등록 직후 화면에 초기 PIN 이 표시되니 직원에게 알려주세요.
PIN 재설정은 `직원관리 → 직원 상세 → 직원정보 수정` 에서 할 수 있습니다.

---

## 3. 처음 설정 순서

1. **설정** — 기본 근무시간(08:00~17:00), 휴게시간, 지각 기준을 회사 기준에 맞춘다.
2. **근무지관리** — 공장·현장의 GPS 좌표와 허용반경을 등록한다.
   근무지에서 `📍 현재 위치 좌표 가져오기` 를 누르면 좌표가 자동 입력됩니다.
3. **현장관리** — 외부 현장을 등록한다. 직원이 출근할 때 선택하게 됩니다.
4. **직원관리** — 직원을 등록하고 직원별 일당·단가를 입력한다.

## 4. 일당 계산방식

직원마다 다르게 지정할 수 있습니다.

| 방식 | 계산 |
|---|---|
| **A · 일당 전액** | 정상근무 시 일당 전액 지급. 연장수당 별도 없음 |
| **B · 시간 비례** | 실근무시간 × (일당 ÷ 기본근무시간) |
| **C · 일당 + 연장수당** | 일당 + (연장시간 × 연장 시간당 단가) |

연장 시간당 단가를 `0` 으로 두면 **일당 ÷ 기본근무시간** 으로 자동 계산합니다.
(예: 250,000원 ÷ 8시간 = 31,250원)

### 근무시간 계산식

```
실근무시간   = 퇴근시간 − 출근시간 − 휴게시간
연장근무시간 = 실근무시간 − 기본근무시간      (음수면 0)
```

근무지 구분(공장/현장)에 따라 해당 일당이 자동으로 적용됩니다.

## 5. 월말 정산

`월별정산` 에서 월을 선택하고 **`전체 정산 실행`** 한 번이면 끝납니다.
근무일수·연장시간·일당·추가수당·공제·최종 지급액이 자동 계산됩니다.

정산을 확정하면 직원이 자기 휴대폰(`내 정산내역`)에서 확인할 수 있고,
`정산 확인` 버튼을 누른 시각이 기록됩니다.

지급은 `지급관리` 에서 처리하며 일부지급·미지급금이 함께 관리됩니다.

> **단가를 바꿔도 이미 지난 근무의 금액은 변하지 않습니다.**
> 단가는 적용 시작일 기준으로 이력이 남고, 금액은 근무기록에 그대로 보존됩니다.

## 6. 데이터 보호

- 출퇴근·급여의 모든 변경은 `수정이력(Audit Log)` 에 **수정 전 / 수정 후 / 수정자 / 시각 / 사유**가 남고 삭제되지 않습니다.
- 직원은 출퇴근 시간을 직접 바꿀 수 없고 **수정 요청**만 가능합니다. 관리자 승인 시에만 반영됩니다.
- 관리자가 출퇴근을 수정할 때는 **수정사유 입력이 필수**입니다.
- 근무기록이 있는 직원은 완전삭제되지 않고 **퇴사처리**됩니다.

### 안전장치

| 상황 | 처리 |
|---|---|
| 중복 출근 | 직원+근무일 고유키로 차단 |
| 퇴근 누락 | 설정된 시간(기본 16시간) 후 자동 마감 + 관리자 확인 표시 |
| 야간근무 (자정 넘김) | 출근일 기준으로 귀속해 정상 계산 |
| 휴게시간 중복 | 겹치는 구간을 병합해 한 번만 차감 |
| 근무지 반경 이탈 | 경고 후 승인 시 출근 가능, 관리자 확인 대상으로 기록 |

## 7. 백업

```bash
npm run backup      # backups/ 폴더에 저장 (pg_dump 있으면 SQL, 없으면 JSON)
```

서버 cron 에 등록해 정기 백업하는 것을 권장합니다.

```bash
0 3 * * * cd /경로/attendance && npm run backup
```

### 퇴근 누락 자동마감 (선택)

`설정` 화면에서 수동 실행하거나, cron 으로 자동화할 수 있습니다.
`.env` 에 `MAINTENANCE_KEY` 를 지정한 뒤:

```bash
0 4 * * * curl -X POST -H "x-maintenance-key: 키값" http://localhost:3000/api/maintenance/auto-close
```

## 8. 자체 서버(NAS·Windows) 배포

모든 설정이 환경변수 기반이므로 Vercel 외에 자체 서버에서도 그대로 동작합니다.

```bash
BUILD_STANDALONE=1 npm run build
node .next/standalone/server.js
```

`DATABASE_URL` 만 해당 서버의 PostgreSQL 로 바꾸면 됩니다.
